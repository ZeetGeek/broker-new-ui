Broker property actions — simple guide

Three features for My Deals / Owner listings: Block property, Cancel representation, and Mark as sold / rented.

Written in simple English so you can share with your team. Open this file in Chrome → click Save as PDF → send to your friend.

Jump to final chart

1. First understand — what is each button for?

Feature In simple words When broker can use it
Block property Hide this property from my list. I don’t want to see it again. Owner is not told. While browsing, or after a deal has already ended. Not while you are actively representing.
Cancel representation I already got permission to sell, but now I want to stop. Owner is told. Only on Representing (accepted) deals.
Mark as sold / rented I sold (or rented) this property. Owner must confirm before the listing goes off the market. Only on Representing deals.
Important: Don’t mix these up. Block = hide for me. Cancel = leave the deal. Mark sold = tell owner the deal is done (owner must say yes).

3. Feature 1 — Block property (step by step)

  1. Broker sees a property they don’t want (wrong area, not useful, etc.).
  2. Broker taps ⋯ menu → Block property.
  3. App asks: “Hide this property from your list? The owner will not be told.”
  4. Broker confirms.
  5. Property disappears from Owner listings for this broker only.
  6. Listing stays published. Other brokers can still see it. Owner status does not change.
  7. If owner invites this broker later on the same property, invite is auto-declined quietly (don’t say “blocked” to the owner).
  8. Broker can unblock later from a Blocked list if needed.
Recommendation: No notification to owner. Blocking is private, like mute.

4. Feature 2 — Cancel representation (step by step)

  1. Broker is on Representing tab (deal already accepted).
  2. Broker taps ⋯ → Cancel representation (wording in app can be: “Stop selling this property”).
  3. App shows a strong confirm: you will lose owner phone / chat on this deal.
  4. Optional: broker writes a short reason.
  5. On confirm, cancel is immediate — no waiting for owner approval.
  6. Owner gets notification: “{Broker name} is no longer representing {property}.”
  7. Card leaves Representing tab.
  8. App may ask: “Also block this property so you don’t see it again?”
Recommendation: Cancel immediately (same idea as owner revoke today). Don’t make owner accept/reject the cancel — that can trap the broker if owner never replies.

5. Feature 3 — Mark as sold / rented (step by step)

  1. Broker is Representing and has closed the deal offline / with a buyer.
  2. Broker taps ⋯ → Mark as sold (or Mark as rented for rent listings).
  3. Broker can optionally add buyer, amount, and a short note.
  4. Listing becomes “Sale waiting for owner” (still visible, but claim is pending).
  5. Owner gets notification with two buttons: Confirm sale or Not sold.
  6. If owner confirms: property marked sold/rented, removed from market, all brokers on that property get closed, proposing broker gets success.
  7. If owner says Not sold: listing goes back to normal, broker stays Representing, broker is notified.
  8. Owner can also mark sold themselves anytime (no broker needed).
Recommendation: Owner must confirm. Reason: property belongs to owner, and more than one broker may be representing the same property. Broker alone should not take the listing off the market for everyone.

6. Who gets notified?

What happened Broker Owner Other brokers on same property
Block property Toast only No No
Cancel representation Toast Yes — must notify No
Broker marks sold (waiting) “Waiting for owner” Yes — Confirm / Not sold Optional soft notice
Owner confirms sale Yes — success Toast Yes — listing closed
Owner rejects sale claim Yes — not confirmed Toast No

Quick rules to remember

  1. Block = private hide. No owner message. Not while Representing.
  2. Cancel representation = leave the deal now. Owner is informed.
  3. Mark sold = broker proposes, owner confirms, then listing closes for everyone.
  4. While sale is waiting for owner, broker should not Cancel until claim is cleared (or must withdraw claim first).
